### 내린 결정

- **카피에서 주어·목적어를 생략하지 않는다.** 「네 단계로 좁힙니다」·「감이 아니라 숫자로
  정합니다」가 지적받았다 — 무엇을 좁히고 정하는지가 문장에 없었다. `home.md` S2 #3 이
  **수식어만** 금지 대상으로 적어 둔 탓에 **생략으로 같은 공허함**을 만드는 형태를 못
  걸렀다. 앵커는 도구 셋이 차례로 무엇을 해 주는지 세 문장으로 바꾸고, **문장마다 주어**를
  줬다(브랜드명 3번 반복은 어색해 뒤 둘은 도구를 주어로). 주어 유무는 테스트로 잠갔다
- **스크롤 진행도는 pin 구간 기준으로 잰다.** progress 0~1 전체로 나누면 첫·마지막 스텝이
  경계에 눌린다. `activeStepFromPinnedProgress`·`pinnedPhase` 를 스토리·랭킹·앵커가 공유하고,
  클릭 목표(`pinnedStepProgress`)는 **그 역함수**다 — 왕복 테스트로 잠갔다
- **축 눈금은 축 전체가 한 단위를 쓴다**(`createAxisTickFormatter`). 소수 자리는
  「서로 다른 글자면 된다」가 아니라 **반올림 오차 < 눈금 간격의 절반**으로 고른다 —
  전자로 하면 `[0, 0.5억, 2.5억]` 이 「0·1억·3억」이 되어 값이 틀린다
- **숫자에는 견줄 것을 붙인다.** 요약 카드가 「라벨 + 숫자」뿐이라 좋은지 나쁜지 알 수
  없었다. 견줄 값은 **이미 받아 둔 응답**(`salesSummary`·`stores`)에 있었다 — 새 호출 없다.
  **막대는 0~1 비율에만** 쓰고(배수를 막대로 그리면 거짓), 견줄 값이 없으면 **지어내지 않고**
  빈 자리로 둔다(자리는 늘 차지 — 카드 높이가 들쭉날쭉해지지 않게)
- **중복 카드는 빼지 않고 바꿔 끼웠다.** 자리를 비우면 칸이 뚫리고, 넣을 값이 실제로 있었다
  (총 점포 → 유사 업종 점포, 상주인구 → 월평균 소득)

### 주의사항

- **turbopack 스테일 캐시에 이번 세션에만 세 번 걸렸다.** 증상이 매번 다르다 — hydration
  실패, 「X is not defined」, SSR 이 **옛 DOM 구조**를 내보냄. 판별: `curl localhost:5173`
  으로 SSR HTML 을 직접 보고 내 변경이 들어 있는지 확인한다. 해결은 서버 정지 → `.next`
  삭제 → 재시작. **콘솔 버퍼도 이전 세션 오류를 계속 들고 있으니** 새 탭에서 다시 볼 것
- **`/analysis` 계열은 pane 이 보여야 렌더된다.** 배경 탭에서는 `body.innerText.length` 가
  13 로 SSR 마크업만 남는다. `tabs_create` 는 기본이 배경이라 반드시 `tabs_select` 로 앞에 낼 것
- **스크롤 구동 UI 는 pane 이 숨겨지면 rAF·scroll 이 아예 발화하지 않는다**(rafFired false,
  scrollEvents 0). 이번엔 사용자가 패널을 열어 줘서 확인했고, 그 덕에 `interaction-polish.md`
  D8-10 의 **B2·B4·B5 미검증이 해소됐다**. 다음에도 스크롤 검증이 필요하면 패널을 열어 달라고 할 것
- **`dev` 서버를 띄우면 `next-env.d.ts` 가 바뀐다**(`.next/dev/types` 경로). 커밋에 섞이지
  않게 `git checkout -- next-env.d.ts` 로 되돌린다. `.claude/launch.json` 도 prettier 검사에
  걸리므로 `qa:verify` 전에 지운다
- **PR 은 develop 에서 딴다.** 한 번 실수로 기능 브랜치 위에 쌓았다가 다시 잡았다 —
  스택 PR 이면 머지가 develop 이 아니라 그 브랜치로 들어간다
- **#229 는 재시도해도 낫지 않는다.** `MAP_008`(503)이 「잠시 후 다시 시도」라고 말하지만
  실제로는 데이터 부재라, FE 의 5xx 재시도 규약이 헛돈다. BE 가 404 로 바꿔야 한다
