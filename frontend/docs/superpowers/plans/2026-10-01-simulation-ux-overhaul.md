## 0. 한 장 요약

**누구를 위한 화면인가.** 상권 데이터에 익숙하지 않은 예비 창업자가 "내 조건이면 처음에 돈이 얼마나 드는지"를 1분 안에 알고 싶어 하는 화면이다. 지금 화면은 기능은 다 갖췄다. 하지만 아래 다섯 가지가 이해와 완주를 막는다.

| #   | 핵심 문제                                                                                                                                                                                               | 영향                                     | 우선순위    |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- | ----------- |

## 2. 사용자 여정 진단

```
진입 ─▶ ① 창업 형태 ─▶ ② 자치구 ─▶ ③ 업종 (+브랜드) ─▶ ④ 매장 크기·층 ─▶ 계산 ─▶ 결과 미리보기 ─▶ 리포트 ─▶ 저장 / 비교
```

| 구간      | 사용자가 느끼는 것                                                              | 원인                                                                                                                                                           |
| --------- | ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 진입      | "무엇을 알려 주는 화면이지? 얼마나 걸리지?"                                     | 설명 한 줄("조건 4개를 고르면…")뿐이다. 무엇을 얻는지(총비용 · 비슷한 브랜드 · 고객 지표)와 소요 시간이 없다                                                   |
| ③ 업종    | "30개 중에 내 업종이 어디 있지?"                                                | 모바일에서 칩 30개가 2열 15줄로 쌓인다. `simulation-catalog.ts`에 이미 6개 대분류(음식점 · 학원 · 레저/오락 · 서비스 · 도소매 · 생활용품)가 있는데 쓰지 않는다 |
| ③ 브랜드  | "내 브랜드가 안 보여" / "몇 단계 남았지?"                                       | 기본 목록 10건이 무작위에 가깝다(평화다방, 빌리엔젤 …). 첫 응답이 실측 5.8초 걸린다. 못 찾았을 때 빠져나갈 길이 없다                                           |
| ④ 크기    | "평으로는 몇이지?" / 입력하다 갑자기 닫힘                                       | 직접 입력이 ㎡만 받는다. 첫 글자에서 섹션이 접히는 버그가 있다(§3-1 B1)                                                                                        |
| 계산 후   | "그래서 이 돈이 뭐로 이루어진 거지?"                                            | 미리보기에는 총액만 있다. 구성은 리포트로 가야 보인다                                                                                                          |
| 리포트    | "임대료가 매달 나가는 건데 총액에 들어가 있나?" / "도넛에서 뭐가 뭔지 모르겠어" | 합계 행이 없다. 같은 색이 반복된다. 「월 임대료」 라벨이 "매달"로 읽힌다                                                                                       |
| 저장·비교 | "저장 버튼이 어디 있지?"                                                        | 저장 버튼(40px, 내용 폭)이 비교 버튼(56px, 남은 폭 전부)보다 작다. 모바일에서는 첫 카드를 지나면 CTA가 사라진다                                                |
