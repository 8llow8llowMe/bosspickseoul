# 구별 현황 지도 선택 강조와 상세 패널 모션 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** 선택한 자치구 폴리곤을 지도에서 강조하고, 데스크톱 상세 패널의 너비 전환과 모바일 지도 배경 클릭 최소화를 추가한다.

**Architecture:** 지도 생성 결과를 자치구 코드·SVG 경로·중심점이 연결된 정적 feature 배열로 바꾸고, 순위 마커와 선택 폴리곤이 같은 feature를 사용하게 한다. 데스크톱은 Top 10 옆 중첩 그리드의 상세 열을 0px에서 고정 너비로 전환하고, 모바일은 지도 배경 버튼이 URL 선택을 건드리지 않고 시트 snap만 collapsed로 바꾼다.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, styled-components, Vitest, Node test runner

- [ ] **Step 3: feature 모델과 조회 함수 구현**

```ts
import type { StatusRankedItem } from '@/types/status'

export type StatusMapFeature = {
  districtCode: string
  path: string
  center: {
    x: number
    y: number
  }
}

export type StatusMapMarker = StatusRankedItem & StatusMapFeature['center']

export function createStatusMapMarkers(
  items: StatusRankedItem[],
  features: readonly StatusMapFeature[],
): StatusMapMarker[] {
  const featureByCode = new Map(
    features.map(feature => [feature.districtCode, feature]),
  )

  return items.slice(0, 10).flatMap(item => {
    const feature = featureByCode.get(item.districtCode)

    return feature ? [{ ...item, ...feature.center }] : []
  })
}

export const findSelectedStatusMapFeature = (
  features: readonly StatusMapFeature[],
  districtCode: string | null,
): StatusMapFeature | null =>
  districtCode
    ? (features.find(feature => feature.districtCode === districtCode) ?? null)
    : null
```
