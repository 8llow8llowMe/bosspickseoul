# 구별 현황 지도 라벨 및 모바일 바텀시트 개선 설계

## 배경

현재 구별 현황 지도는 서울 자치구 폴리곤을 하나의 실루엣처럼 표시하고,
Top10 자치구만 원형 순위 마커로 구분한다. 모바일 바텀시트는 접힌 상태에서도
화면의 54%를 차지해 지도를 충분히 보기 어렵고, 지도 영역 높이도 한 화면에서
전체 윤곽을 파악하기에는 크다.

이번 작업은 다음 목표를 갖는다.

- 선택 전에도 서울 25개 자치구의 경계와 이름을 확인할 수 있게 한다.
- Top10 자치구는 구 이름 아래에 현재 지표 순위를 표시한다.
- 모바일에서 지도를 배경으로 두고 바텀시트가 그 위를 오가는 지도 앱 형태를
  만든다.
- 최소화 상태에서는 핸들만 남겨 지도 가시 영역을 최대화한다.
- `/status` 모바일 화면에서는 불필요한 공통 푸터를 숨긴다.

## 범위

### 포함

- 서울 25개 자치구 기본 경계선
- 25개 자치구 이름 라벨
- Top10 자치구 이름 아래 순위 표시
- 선택 자치구 폴리곤과 라벨 강조
- 모바일 지도 스테이지 높이 제한
- 52px 최소화와 66% 확장으로 구성된 2단 바텀시트
- 지도 탭, 핸들 탭, 드래그, 구 라벨 선택에 따른 시트 전환
- `/status` 페이지 모바일 푸터 숨김
- 관련 단위·컴포넌트·브라우저 검증

### 제외

- Top10 밖 자치구의 순위 또는 상세 데이터 생성
- Top10 밖 자치구 선택
- 백엔드 API 및 데이터베이스 변경
- 패키지, 락파일, 빌드·배포 설정 변경
- 다른 페이지의 지도 또는 모바일 푸터 정책 변경
- 3단 이상의 바텀시트 스냅

## 지도 표현

### 폴리곤

- `SEOUL_STATUS_FEATURES`의 25개 path를 모두 렌더링한다.
- 기본 자치구 path는 중립색 `1px` 경계선을 갖는다.
- 기본 채움은 기존 muted surface를 유지한다.
- 선택 자치구는 primary 색상 `3px` 경계선과 `fill-opacity: 0.5`를 유지한다.
- 선택 강조 path는 기본 path 위에 한 번만 추가한다.

### 구 이름과 순위

- 기존 feature의 `center` 좌표를 각 자치구 라벨 중심으로 사용한다.
- 구 코드와 기존 지역 데이터의 구 이름을 결합해 25개 이름을 만든다.
- Top10 API 응답에 포함된 구는 이름 아래 현재 지표 순위 `1~10`을 표시한다.
- Top10 밖 15개 구는 이름만 표시하고 클릭 대상에서 제외한다.
- 기존 원형 숫자 마커는 제거한다.
- Top10 라벨은 버튼으로 렌더링하며 구 이름, 지표명, 순위를 접근 가능한 이름에
  포함한다.
- 선택한 Top10 라벨은 primary 테두리·배경·글자색으로 강조한다.
- 작은 자치구에서도 폴리곤을 가리지 않도록 라벨은 2줄의 컴팩트한 형태를
  사용하고, 긴 설명이나 지표 값은 지도에 추가하지 않는다.

## 지도 표시 모델

지도 렌더링 전에 다음 정보를 갖는 표시 모델을 만든다.

```ts
type StatusMapLabel = {
  districtCode: string
  districtName: string
  x: number
  y: number
  rank: number | null
  isTopTen: boolean
}
```

- feature 목록이 25개 라벨의 기준이다.
- 기존 지역 데이터에서 구 코드에 해당하는 이름을 찾는다.
- 현재 지표의 Top10 목록을 코드 기준으로 결합한다.
- Top10에 포함되면 `rank`를 사용하고, 아니면 `null`을 사용한다.
- 표시 모델은 순수 함수로 만들어 데이터 누락과 순서 변화를 단위 테스트한다.
- 백엔드 응답 형식은 변경하지 않는다.

## 모바일 지도 스테이지

- breakpoint는 기존과 동일한 `max-width: 1023px`를 사용한다.
- 지도 스테이지 높이는 `clamp(360px, 62dvh, 560px)`로 고정한다.
- 지도는 스테이지 전체에 absolute layer로 배치한다.
- 바텀시트는 같은 스테이지 안에서 지도 위에 absolute layer로 배치한다.
- 지도 캔버스는 고정 aspect ratio를 해제하고 스테이지의 가용 높이를 사용한다.
- 서울 전체 윤곽은 `preserveAspectRatio="xMidYMid meet"`으로 한눈에 보이게 한다.

## 모바일 바텀시트

### 두 상태

- `collapsed`: 높이 52px. 핸들과 접근성 버튼만 표시하고 본문은 보이지 않는다.
- `expanded`: `min(66%, calc(100% - 180px))`. 스테이지 높이의 66%를
  사용하되 지도 가시 높이를 최소 180px 보장한다.

중간 스냅은 만들지 않는다.

### 초기 상태

- 모바일 최초 진입에서는 Top10을 바로 확인할 수 있도록 `expanded`로 시작한다.
- 유효한 `district` 쿼리가 있으면 해당 상세 콘텐츠로 `expanded` 상태에서
  시작한다.
- 지표 변경 시 선택을 해제하고 Top10 콘텐츠를 `expanded`로 표시한다.

### 입력 동작

| 현재 상태 | 입력                 | 결과                       |
| --------- | -------------------- | -------------------------- |
| collapsed | 핸들 탭              | expanded                   |
| expanded  | 핸들 탭              | collapsed                  |
| collapsed | 핸들을 위로 드래그   | expanded                   |
| expanded  | 핸들을 아래로 드래그 | collapsed                  |
| collapsed | 지도 배경 탭         | expanded                   |
| expanded  | 지도 배경 탭         | collapsed                  |
| 모든 상태 | Top10 구 라벨 탭     | 해당 상세 선택 후 expanded |

- 지도 배경 탭은 선택 자치구와 URL의 `district`를 변경하지 않는다.
- Top10 구 라벨 선택만 `district` 쿼리를 변경한다.
- 시트 내부 버튼이나 스크롤 제스처는 지도 배경 탭으로 전달하지 않는다.
- drag와 click을 구분하는 기존 tolerance를 유지한다.
- `prefers-reduced-motion`에서는 높이 전환 애니메이션을 제거한다.

### 콘텐츠와 스크롤

- expanded 상태의 시트 본문만 `overflow-y: auto`를 사용한다.
- collapsed 상태에서는 본문을 시각·포인터·키보드 탐색에서 제외한다.
- Top10과 상세 전환 시 본문 스크롤 위치를 0으로 되돌린다.
- 상세 선택 시 기존 포커스 이동과 오류·재시도 동작을 유지한다.

## 모바일 푸터

- 공통 shell layout 구조는 유지한다.
- `/status`의 main element에 모바일 푸터 숨김을 나타내는 안정적인 data
  attribute를 둔다.
- SiteFooter는 해당 main 바로 다음에 있을 때만 `max-width: 1023px`에서
  숨긴다.
- 데스크톱 `/status`와 다른 모든 페이지의 푸터는 그대로 표시한다.
- pathname 기반 전역 숨김이나 다른 route group 변경은 하지 않는다.

## 로딩·오류·빈 상태

- Top10 로딩·오류·재시도 UI를 유지한다.
- 상세 로딩·오류·재시도 UI를 유지한다.
- Top10 데이터가 비어 있으면 25개 기본 폴리곤과 구 이름은 표시하고 순위는
  표시하지 않는다.
- 구 이름 매핑이 누락된 feature는 코드가 화면에 노출되지 않도록 해당 라벨을
  제외하되 폴리곤은 유지한다.

## 접근성

- Top10 라벨 버튼은 `aria-pressed`로 선택 상태를 전달한다.
- 접근 가능한 이름은 `순위, 구 이름, 현재 지표`를 포함한다.
- non-Top10 이름은 정보성 텍스트이며 포커스 대상이 아니다.
- 바텀시트 핸들은 현재 상태에 맞춰 “펼치기” 또는 “접기”로 이름을 바꾼다.
- collapsed 상태의 본문은 스크린리더와 키보드 탐색에서 제외한다.
- 지도 배경 버튼은 현재 수행할 동작에 따라 “바텀시트 펼치기” 또는
  “바텀시트 최소화”로 이름을 바꾼다.

## 테스트와 검증

### 단위 테스트

- 25개 feature에서 25개 구 이름 라벨 생성
- 입력 순서와 관계없이 Top10에만 `rank` 연결
- Top10 밖 자치구의 `rank`가 `null`
- 선택 feature 조회 유지
- 52px과 66% 높이를 기준으로 한 양방향 drag 판정
- 지도 탭의 collapsed/expanded 전환
- 유효하지 않은 수치와 작은 화면에서 안전한 상태 유지

### 컴포넌트 테스트

- 25개 기본 path에 경계선 스타일 적용
- 25개 구 이름과 Top10 순위만 렌더링
- 선택 path의 50% 채움과 3px 경계선 유지
- 원형 순위 마커 제거
- collapsed 본문 비노출과 expanded 본문 노출
- 지도 배경 버튼의 상태별 접근 가능한 이름
- `/status` 모바일 푸터 선택자 적용

### 브라우저 검증

- 1280px 데스크톱: 25개 경계·이름, Top10 순위, 선택 강조, 기존 3열 상세 배치
- 768px 태블릿: 지도 스테이지, 52px/66% 스냅, 푸터 숨김
- 390px 모바일: 지도 전체 윤곽, 핸들만 남은 최소화, 탭·드래그 확장
- 모바일 선택 유지: 지도 배경 토글 후 URL·선택 폴리곤 유지
- 모바일 라벨 선택: URL 변경, 상세 교체, 시트 확장
- 콘솔 오류와 가로 스크롤 없음

## 완료 기준

- 선택 전에도 서울 25개 구 경계와 이름이 구분된다.
- Top10 구에만 이름 아래 순위가 표시된다.
- 선택 구의 50% 채움과 primary 경계가 데스크톱·모바일에서 유지된다.
- 모바일 최소화 상태는 52px 핸들만 차지한다.
- 모바일 확장 상태는 스테이지의 약 66%를 차지한다.
- 지도 탭, 핸들 탭, 양방향 drag, 구 라벨 선택이 정의한 상태 전환과 일치한다.
- 모바일 지도 스테이지는 360~560px 범위이며 서울 전체 윤곽을 한눈에
  보여준다.
- `/status` 모바일에서만 푸터가 숨겨진다.
- 기존 API와 데스크톱 상세 UI에 회귀가 없다.
- 관련 자동 검사와 브라우저 검증이 통과한다.
