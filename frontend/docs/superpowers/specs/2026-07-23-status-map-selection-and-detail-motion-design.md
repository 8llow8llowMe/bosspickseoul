# 구별 현황 지도 선택 강조와 상세 패널 모션 설계

## 배경

`/status` 화면은 Top 10 자치구의 위치를 순위 마커로 표시하지만, 선택한 자치구의 실제 경계는 구분하지 않는다. 데스크톱에서는 자치구를 선택하는 순간 상세 열과 지도의 너비가 즉시 바뀌어 상세 영역이 자연스럽게 열리는 느낌도 부족하다. 모바일 바텀시트는 핸들 드래그와 클릭으로 높이를 전환할 수 있지만, 지도를 다시 확인하려면 핸들까지 이동해야 한다.

## 목표

- 선택한 자치구 폴리곤을 데스크톱과 모바일 지도에서 동일하게 강조한다.
- 데스크톱 상세 패널이 왼쪽에서 오른쪽으로 너비를 확보하며 자연스럽게 나타나게 한다.
- 모바일 지도 배경을 누르면 선택 상태를 유지한 채 바텀시트만 최소화한다.
- 기존 API, 로딩·오류·빈 상태, URL 선택 상태와 Top 10 동작을 보존한다.

## 범위 밖

- 백엔드 API와 Next.js BFF 변경
- 외부 지도 API 또는 신규 UI·모션 패키지 도입
- 지도 확대·축소, 이동, 툴팁 기능 추가
- 모바일 단일 스냅 높이 정책 변경
- GeoJSON 원본 교체 또는 원출처·라이선스 확정

## 지도 데이터 구조

현재 생성 파일은 SVG 경로 배열과 자치구 중심점 객체를 별도로 제공한다. 폴리곤 선택을 배열 순서에 의존하지 않도록 생성 결과를 자치구 코드 중심 구조로 바꾼다.

각 생성 항목은 다음 정보를 연결한다.

- `districtCode`: 백엔드 Top 10 응답과 연결할 5자리 자치구 코드
- `path`: 800×620 viewBox에 투영하고 단순화한 SVG 경로
- `center`: 순위 마커를 배치할 폴리곤 내부 좌표

지도 생성 스크립트는 원본 GeoJSON의 서울 25개 자치구를 검증하고, 코드 중복·잘못된 좌표·폴리곤 밖 중심점을 기존과 동일하게 거부한다. 생성 파일에는 원본 파일명과 SHA-256 해시를 유지한다.

## 선택 폴리곤 표현

기본 폴리곤은 현재 중립 배경색을 유지한다. 선택된 자치구는 동일한 경로를 SVG의 마지막 폴리곤 레이어에 한 번 더 렌더링한다. 마지막에 그려 인접 구의 기본 경로에 테두리가 가려지지 않게 한다.

- 테두리: `var(--color-primary-600)`, 3px
- 내부: `var(--color-primary-600)`, `fill-opacity: 0.5`
- 순위 마커: 선택 폴리곤보다 높은 레이어 유지
- 선택 없음 또는 현재 Top 10에 없는 코드: 강조 폴리곤 없음

강조 폴리곤은 시각 정보이며 별도의 포커스 대상을 만들지 않는다. 지도 마커의 기존 접근 가능한 이름과 선택 상태를 유지한다.

## 데스크톱 상세 패널 모션

데스크톱의 첫 번째 열은 Top 10 고정 너비를 유지한다. 두 번째 영역은 상세 패널과 지도를 포함하는 중첩 그리드로 구성한다.

- 선택 전: `0px + 지도`
- 선택 후: `Top 10과 동일한 너비 + 지도`
- 상세 열 간격: `0px`에서 기존 열 간격으로 함께 전환
- 상세 패널: 너비 전환과 함께 투명도·짧은 수평 이동을 적용
- 지도: 상세 패널이 확보하는 너비만큼 자연스럽게 축소

모션은 기존 디자인 토큰의 standard duration과 easing을 사용한다. `prefers-reduced-motion: reduce` 환경에서는 너비·이동·투명도 전환을 제거하고 최종 상태를 즉시 표시한다. 자치구를 다른 구로 바꿀 때는 이미 열린 상세 열의 너비를 다시 닫지 않고 내용만 갱신한다.

## 모바일 바텀시트 상호작용

기존 핸들 드래그와 핸들 클릭의 `collapsed`/`expanded` 전환은 유지한다. `StatusMap`에는 선택적인 지도 배경 클릭 콜백을 제공하고 모바일에서만 연결한다.

- 지도 배경 클릭: 현재 선택 코드와 URL 쿼리를 유지하고 `snap`만 `collapsed`로 변경
- 순위 마커 클릭: 이벤트 전파를 차단하고 해당 구를 선택한 뒤 상세 바텀시트를 `expanded`로 변경
- Top 10 복귀: 기존 상세 내부의 뒤로 가기 동작으로 선택 해제
- 단일 스냅 화면: 기존 고정 높이 정책을 유지하므로 배경 클릭이 시각적 높이를 바꾸지 않음

지도 배경 클릭 영역은 마커 버튼과 중첩되지 않는 실제 버튼으로 제공해 포인터와 키보드에서 동일한 동작을 제공한다. 데스크톱에는 이 버튼을 렌더링하지 않는다.

## 데이터 흐름과 상태 보존

Top 10과 상세 데이터 호출은 기존 경로를 유지한다.

1. `GET /api/bff/districts/top-ten`
2. 선택 시 `GET /api/bff/districts/{districtCode}`
3. `districtCode`로 Top 10 항목, 지도 폴리곤, 중심점을 연결
4. 모바일 시트 최소화는 로컬 `snap` 상태만 변경

지도 배경 클릭은 `district` 쿼리를 제거하지 않으므로 새 API 요청이나 상세 캐시 초기화를 유발하지 않는다.

## 오류와 경계 상태

- Top 10 로딩·오류·빈 상태는 기존 피드백 컴포넌트를 유지한다.
- 상세 로딩·오류·재시도는 열린 상세 패널 또는 모바일 시트 안에서 기존대로 표시한다.
- API 응답에 지도 중심점이나 폴리곤이 없는 자치구 코드가 들어오면 해당 지도 표시만 생략하고 Top 10 목록은 유지한다.
- 선택 해제 시 강조 폴리곤을 제거하고 데스크톱 상세 열을 닫는다.
- 모션 진행 중 빠르게 선택을 바꿔도 선택 코드를 단일 기준으로 사용한다.

## 테스트와 검증

### 자동 테스트

- 지도 생성 결과가 서울 25개 자치구의 고유 코드·경로·중심점을 포함하는지 검증
- 선택 코드로 정확한 폴리곤을 찾고, 잘못된 코드에는 강조 대상을 만들지 않는지 검증
- 지도 배경 최소화가 선택 코드 변경 없이 `collapsed`만 요청하는지 검증
- 기존 바텀시트 드래그 경계, 콘텐츠 전환, URL 정규화 테스트 회귀 확인
- 전체 lint, TypeScript 검사, 단위 테스트, production build 실행

### 수동 검증

- 데스크톱: 선택 전 `Top 10 + 지도`, 선택 후 `Top 10 + 상세 + 지도` 전환 확인
- 데스크톱: 상세 패널이 왼쪽에서 오른쪽으로 열리고 지도가 함께 부드럽게 축소되는지 확인
- 데스크톱·모바일: 선택 폴리곤의 3px 테두리와 50% 내부 강조 확인
- 모바일: 핸들 아래 드래그와 지도 배경 클릭으로 시트 최소화 확인
- 모바일: 최소화 후 선택 폴리곤 유지, 마커 클릭 시 다른 구 선택·상세 확장 확인
- 모션 감소 설정과 브라우저 콘솔 오류 확인

## 완료 조건

- 선택한 구의 경계가 데스크톱과 모바일에서 명확히 구분된다.
- 데스크톱 상세 열이 실제 너비 전환으로 열리고 닫힌다.
- 모바일 지도 배경 클릭이 선택을 유지한 채 바텀시트를 최소화한다.
- 기존 API 계약과 오류·로딩·빈 상태가 유지된다.
- 관련 자동 검사와 수동 브라우저 검증 결과가 기록된다.
