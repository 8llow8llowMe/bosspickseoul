## S1. 기능 개요

simulation은 V2 백엔드 계약이 확정되기 전까지 실패가 예정된 네트워크 요청을 발생시키지 않고, 기능 준비 상태와 대체 이동 경로를 일관되게 제공한다. 실제 계산·저장·비교·공유 기능은 Swagger 계약과 Gateway route가 준비된 후 별도 구현 PR로 재개한다.

```
보호 라우트 진입 → 인증 확인 → 화면별 준비 상태 안내 → 상권분석 또는 홈으로 이동
```
