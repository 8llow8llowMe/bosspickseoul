## S1. 기능 개요

사용자는 지도와 단계형 패널에서 분석 대상을 명확하게 좁히고, 선택 상태가 담긴 URL로 상세 분석 결과를 확인·공유한다. 지도는 선택을 돕는 시각적 인터페이스이며, 패널과 URL이 선택 상태의 정본이다.

```text
지역 탐색 → 상권·업종 선택 → URL 동기화 → 분석 결과 라우트 → 탭별 지표 조회
```
