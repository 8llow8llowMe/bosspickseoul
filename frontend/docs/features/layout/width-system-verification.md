# 앱 폭 체계 — 실측 검증 기록

> **측정일**: 2026-09-06
> **대상**: `feature/fe/app-width-system` (Task 1~8 적용 후)
> **설계**: [2026-09-04-app-width-system-design](../../superpowers/specs/2026-09-04-app-width-system-design.md)
> **방법**: dev 서버(5173) + 브라우저 실측. `getBoundingClientRect()` 로 헤더 Inner 와
> 본문 셸의 `left`/`right` 를 비교한다. 1440 이상에서는 스크린샷이 축소되어 눈으로는
> 픽셀을 못 재므로 **수치가 유일한 증거다.**

## 불변식

> **개방 라우트에서 헤더 Inner 의 `left`/`right` == 본문 셸의 `left`/`right`**

셸 폭은 `--w-shell` = `calc(100% - 20px * 2)` 하나뿐이므로, 기대값은 뷰포트 폭에서
자동으로 나온다: 1440 → `[20, 1420]` · 1920 → `[20, 1900]` · 2560 → `[20, 2540]`.

## `auto-fit` 열 폭주 차단

`/status` 자치구 상세카드의 지표 그리드는 `repeat(auto-fit, minmax(140px, 1fr))` 이라
열 수에 상한이 없었다. 셸에서 폭 상한을 걷어내면 2560px 칸에서 18열까지 간다.

| 폭   | 열 수 | 그리드 폭              |
| ---- | ----- | ---------------------- |
| 2560 | **6** | 1400 (`--w-wide` 상한) |

## 미검증 — 이 브랜치가 확인하지 못한 것

**조용히 넘기지 않는다.** 아래 두 라우트는 이번 실측 대상에서 빠졌다.

| 라우트            | 이유                                                                       | 어떻게 확인하나                                                              |
| ----------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `/community/[id]` | dev 백엔드에 게시글이 0건이라 상세를 열 수 없다(BE 이슈 #190 과 같은 원인) | 글이 하나라도 생기면 1920 에서 헤더 대비 `[0, 0]` 과 본문 열 720 상한을 잰다 |
| `/profile/**`     | 미들웨어 보호 라우트라 로그인이 필요하다(`middleware.ts:14`)               | 로그인한 사람이 1920 에서 셸 `[20, 1900]` 과 설정 화면 폼 폭 880 을 확인한다 |

`/recommend` 는 지도 셸이라 폭 상한을 가진 본문 컨테이너가 없다 — 어긋날 대상이 없어
표에서 뺐다(측정 실패가 아니다).

## 측정 시 걸린 함정

다음 사람이 같은 데서 시간을 버리지 않도록 적는다.

| 증상                                                                                                             | 원인                                                  | 대응                                                                       |
| ---------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- | -------------------------------------------------------------------------- |
| 코드를 고쳐도 옛 폭이 그대로 보인다. 하이드레이션 불일치(styled 클래스 해시가 서버/클라이언트에서 다름)까지 뜬다 | turbopack 스테일 캐시                                 | dev 서버를 **끄고 `.next` 를 지운 뒤** 다시 켠다. 새로고침만으로는 안 된다 |
| `getBoundingClientRect()` 가 전부 0 이고 `main` 부모가 `display: none` 으로 읽힌다                               | 브라우저 pane 이 숨겨져 있으면 레이아웃·rAF 가 멈춘다 | 재려면 **탭을 앞으로 꺼낸 뒤(front) 바로** 잰다                            |
