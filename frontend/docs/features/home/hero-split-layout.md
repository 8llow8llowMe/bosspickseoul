# home — 히어로 좌우 분할 (카드가 지도를 가리지 않게) 세부 명세

> **작성일**: 2026-10-02
> **공통 명세**: [home 공통 명세](./home.md) — S3 #1(Hero)
> **선행**: [hero-picker-and-mobile-first-screen](./hero-picker-and-mobile-first-screen.md)(PR #505) — 피커·모바일 카드 우선·자동 시연
> **작성자**: Claude Code
> **상태**: 명세 확정 · 구현 중
> **성격**: **시험 적용.** 사용자가 「바꿔 보고 별로면 다시 돌린다」고 했다 — 창 장식은 지우지 않고 **숨긴다**(D4-2)

---

## D0. 배경

히어로 카드(유리 창)가 지도 **가운데 위**에 떠 있어, 자치구 중심점이 카드 밑에 깔린다.

| 뷰포트   | 카드에 가려지는 구(중심점 기준)                                               |
| -------- | ----------------------------------------------------------------------------- |
| 1440×900 | **12/25** — 종로·중구·용산·성동·동대문·성북·은평·서대문·마포·영등포·동작·강남 |
| 1024×768 | **14/25** — 위 + 광진·강북                                                    |

피커(PR #505)로 「고르기」는 되지만, 지도 **호버 툴팁**(홈 최고의 인터랙션)은 도심·강남에서 쓸 수 없다. 카드 드래그·접기·독
축소가 있지만 발견하는 사람이 드물다. 그래서 겹침 자체를 없앤다.

| U1  | 배치         | **좌우 분할** — 카드 왼쪽 · 지도 오른쪽                                 |
| U2  | 분할 기준 폭 | **900px 이상** 분할, 899px 이하는 위아래(카드 → 지도)                   |

| U4  | PR           | #505 와 분리한 **후속 PR**                                              |

## D1. 기능 개요

```
≥900px : [ 카드 (360~460px) ] [ 지도 (나머지, 스테이지 높이) ]   ← 겹침 0. 카드는 세로 가운데
641~899: [ 카드 ] → [ 지도 (aspect-ratio) ] → [ 캡션 ]           ← 모바일과 같은 순서·같은 지도 높이 규칙
≤640px : 변경 없음(PR #505)
```

- 폭에 따른 **동작**(모바일 탭 = 피커 선택, 호버 툴팁 끄기)은 그대로 **≤640px** 기준이다. 이 문서는 **배치**만 바꾼다.
  641~899 는 위아래로 쌓이지만 마우스가 있으면 호버 툴팁·클릭 이동이 그대로 동작한다.

## D2. 동작 요구사항

| #   | 요구사항                                                                                                                 |
| --- | ------------------------------------------------------------------------------------------------------------------------ |
| 1   | ≥900px 에서 카드와 지도가 **겹치지 않는다** — 25개 자치구 중심점 중 카드 영역 안에 있는 것이 0 개다(1440×900 · 1024×768) |
| 2   | ≥900px 에서 히어로는 한 화면(`100dvh - 헤더`)이고, 지도는 오른쪽 칸 높이에 맞춰 축소된다(`preserveAspectRatio meet`)     |
| 3   | ≤899px 에서 [카드][지도][캡션] 순서, 지도는 `aspect-ratio: 800 / 620`, 캡션은 지도 아래 흐름                             |
| 4   | 창 장식(제목줄·신호등·드래그·접기·독)을 렌더하지 않는다. `HERO_WINDOW_CHROME` 상수 하나로 다시 켤 수 있다                |
| 5   | 장식을 숨긴 카드는 위 여백을 본문과 같게 준다(제목줄이 있던 자리를 비우지 않는다)                                        |
| 6   | 자동 시연은 그대로 강동구 · 1회. 카드가 지도를 덮지 않으므로 카드 피하기(`demoAvoidRight`)를 넘기지 않는다               |
| 7   | 375×812 첫 화면 수치(h1 0.18 · 첫 CTA 0.48 화면)가 나빠지지 않는다                                                       |

## D3. 아키텍처

- 분할 기준은 `layout-constants.ts` 의 `HERO_STACKED_MEDIA = '(max-width: 899px)'` 한 곳에 둔다. 히어로(`hero-section.tsx`)와 지도
  (`seoul-districts-map.tsx` 의 지도 높이·캡션 위치)가 같은 값을 쓴다. **동작** 판정용 640px(`isMobileViewport`)과는 다른 값이다.
- `HeroStage` 는 ≥900px 에서 `display: grid; grid-template-columns: minmax(360px, 460px) minmax(0, 1fr)`. 자식은 `CardLayer` 와
  `MapScreen`(`display: contents` → `MapLayer` 가 둘째 칸). 카드 칸과 지도 칸 사이 `column-gap: 48px`.
- `CardLayer` 는 더 이상 `position: absolute` 오버레이가 아니다(모든 폭에서 흐름 배치). 오버레이를 위해 있던 `pointer-events: none`·
  `z-index` 도 필요 없다.
- `HeroWindow` 에 `chrome: boolean` prop. `false` 면 `TitleBar` 를 렌더하지 않는다 → 드래그 핸들·신호등·접기·창 확대 점이 함께
  사라지고, 닫기가 없으니 독 버튼도 나오지 않는다. `HeroSection` 은 `HERO_WINDOW_CHROME`(= `false`)을 넘기고, 드래그도
  `HERO_WINDOW_CHROME && …` 일 때만 켠다. 독·접기 상태 코드와 `use-window-drag.ts`·`window-display.ts` 는 지우지 않는다(U3).
- `placeBesideRect`·`demoAvoidRight` prop 은 남기되 넘기지 않는다 — 오버레이로 되돌릴 때 다시 넘긴다.

## D4. 상세

### D4-1. ≥900px 배치

| 요소    | 규칙                                                                                                                 |
| ------- | -------------------------------------------------------------------------------------------------------------------- |
| 카드 칸 | `minmax(360px, 460px)` · 세로 가운데(`align-self: center`). 카드 폭은 칸 폭(`width: 100%`)                           |
| 지도 칸 | `minmax(0, 1fr)` · `height: 100%`(스테이지 높이). svg 는 `width/height: 100%` + `meet` — 폭·높이 중 작은 쪽에 맞춘다 |
| 캡션    | 지도 칸 좌하단(`position: absolute` — 지금과 같다)                                                                   |

### D4-2. 창 장식 숨김

- 렌더하지 않는 것: 제목줄(「서울 상권 데이터 분석」), 신호등 3점(닫기·접기·창 확대 링크), 제목줄 드래그.
- 결과적으로 사라지는 상태 전이: 접기(`minimized`), 닫기 → 독(`closed`), 독 → 열기 애니메이션. 상태값은 `'open'` 에서 움직이지 않는다.
- 카드 본문 위 패딩: 장식이 있을 때 16px(제목줄 아래) → 없을 때 **40px**(좌우와 같게), ≤640px 는 **24px**.
- 계측 `home_hero_cta_click { cta: 'window_max' }` 는 더 이상 나가지 않는다(창 확대 점이 없다). 이벤트 정의는 남긴다.

### D4-3. 641~899px

≤640px 의 **배치 규칙만** 899px 까지 넓힌다: `Hero`·`Inner`·`HeroStage` 높이 해제, `MapScreen` 흐름 배치, `MapLayer` 위 간격 24px,
`MapSvg` `aspect-ratio`, 캡션 `position: static`. 카드 패딩·글자 크기 같은 **모바일 표현 규칙은 640px 그대로**다.
