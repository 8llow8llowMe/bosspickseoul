## D1. GA4 로딩

1. **측정 ID 는 `NEXT_PUBLIC_GA_MEASUREMENT_ID`(빌드 시점)** 다. 비어 있으면 스크립트·클릭 수집기를 아예 렌더하지 않는다 — 로컬 빌드와 ID 를 넣지 않은 환경은 수집 0. FCM 처럼 「없으면 스스로 꺼진다」 규칙이라 Jenkins 필수 key 목록에 넣지 않는다.
   - `NEXT_PUBLIC_FIREBASE_MEASUREMENT_ID` 를 재사용하지 않는다. 그 값은 Firebase 앱(푸시)에 묶인 ID 라 웹 통계와 수명이 다르다.
2. `app/layout.tsx` 에 `<GoogleAnalytics />` 를 둔다. `next/script` `afterInteractive` 로 `gtag.js` 를 싣고 `gtag('config', ID)` 한 번. 패키지(`@next/third-parties`)를 추가하지 않는다 — 필요한 것이 스크립트 두 줄이고 이벤트 함수는 직접 타입을 걸고 싶어서다.
   - SPA 이동 페이지뷰는 GA4 「향상된 측정 → 브라우저 기록 이벤트 기반 페이지 변경」(기본 켜짐)이 잡는다. 코드에서 `page_view` 를 따로 쏘지 않는다(중복 집계 방지).
3. **사용자가 GA 관리 화면에서 할 일**: 웹 스트림 생성 → 측정 ID 를 Vault `kv/bosspickseoul/frontend/prod/env` 에 넣기 → 데이터 보관 기간 14개월 → Google 신호 데이터 끄기 → 향상된 측정의 「브라우저 기록 이벤트」 켜짐 확인. 처리방침 1.1 이 이 설정값을 전제로 쓰였다(D4).
4. **dev 에는 prod 측정 ID 를 넣지 않는다.** `develop` 대상 PR 빌드도 dev Vault 값을 전부 주입받으므로(`Jenkinsfile.frontend-common.groovy` `readBuildEnvValues`), dev 에 넣으면 PR·dev 빌드와 QA 클릭이 운영 통계에 섞인다. dev 계측을 보고 싶으면 **별도 웹 스트림(별도 측정 ID)** 을 만들어 dev 경로에만 넣는다.
5. Google 신호·광고 개인화 신호는 관리 화면 설정과 별개로 **태그가 끈다**(`buildGaInitScript` 의 `allow_google_signals: false`, `allow_ad_personalization_signals: false`). 처리방침 제9조의 약속을 코드가 지킨다.
6. 시행일(2026-10-09) 전 수집을 코드로 막지는 않는다 — 시행일이 지나면 죽은 분기가 되고, 루트 레이아웃이 정적이라 날짜 비교가 빌드 시점에 굳는다. 「시행일 이후 Vault 에 넣기」 절차(`.env.example` · `deployment.md`)로 지킨다.

- 이름은 GA4 규칙(영문·숫자·밑줄, 40자 이내)을 지킨다. 홈 이벤트는 `home_` 접두사로 묶는다.
- **`home_story_step_view` 는 「봤다」보다 「지나갔다」에 가깝다.** 고정 스크롤 모드에서는 섹션을 훑고 지나가도 02→04 가 차례로 찍히고, 다시 올라가면 또 찍힌다. 몰입도로 읽으려면 탭 클릭(모바일) 구간과 나눠 보거나 머무름 조건을 후속으로 더한다. 판단 흐름 도달률(스크롤 깊이)로 읽는 것이 정확하다.
- 화면 주소(`page_location`)는 GA 가 기본으로 싣는다. 커뮤니티 검색(`?keyword=`)처럼 주소에 담긴 검색어도 함께 가므로 처리방침 제3조에 「주소에 담긴 검색어 포함」을 적었다. 회원 번호·토큰·이메일을 주소에 싣는 화면은 없다(2026-10-02 라우트 전수 확인).
- 링크 클릭은 `data-track` 속성 + 문서 클릭 위임으로 잡는다. 서버 컴포넌트(벤토)에도 클라이언트 래퍼 없이 붙고, 링크 이동을 막지 않는다. 속성은 `trackAttrs(name, params)` 로만 만든다 — 이름·파라미터 타입을 컴파일러가 검사한다.
- 측정 ID 가 없으면 `trackEvent` 는 아무것도 하지 않는다(`window.gtag` 없음).

## D3. 판단 흐름 CTA 딥링크

1. **02 「이 조건으로 AI 리포트 받기」는 조건을 싣지 않고 빈 `/analysis` 로 갔다.** → `/analysis?districtCode=<선택 자치구>` 로 보낸다. `/analysis` 는 자치구만 골라도 자치구 단위 AI 리포트 카드를 보여 준다(`resolveAiReportLevel`).
   - **업종은 싣지 않는다.** `/analysis` 는 행정동을 고르는 순간 업종을 지운다(`selectAnalysisValue` `administration` 분기). 실어 봐야 한 번의 클릭에 사라지고, 그 동작을 바꾸는 것은 분석 화면의 결정이라 이 슬라이스 밖이다.
   - 그래서 문구에서 「이 조건으로」를 뺀다 → `{자치구} 분석하고 AI 리포트 받기`. 버튼이 약속하는 것과 도착 화면이 일치해야 한다.
2. **03 「상권 추천받기」** → 홈 03 데모가 실제로 쓴 조건(자치구 · 첫 행정동 · 업종)을 `/recommend` 에 싣고 `view=results` 로 **결과 화면에 바로 착지**한다. `parseRecommendUrlState` 가 이미 이 형식을 복원한다. 홈에서 본 추천과 같은 조건이라 도착 화면이 홈 미리보기의 연장이다.
   - 행정동이 아직 안 풀렸으면(연쇄 로딩 중·실패) 자치구·업종만 실어 조건 화면에 둔다. 문구는 행정동이 있을 때만 `이 조건으로 추천 결과 보기`, 없으면 기존 `상권 추천받기`.
   - `createRecommendHrefFromCodes` 에 `view` 옵션을 더한다(분석 → 추천 딥링크의 기존 출력은 그대로).
3. 01·04 는 그대로다. 01 은 조건을 약속하지 않고, 04 는 고정 예시다.
4. 03 의 결과 착지·문구는 홈 미리보기가 **실데이터**일 때만이다. 행정동이 풀렸어도 상권이 비거나 추천이 실패해 예시(`isSample`)로 떨어졌으면 행정동을 넘기지 않아 조건 화면에 둔다.
5. CTA 계산은 `resolveStoryCta(step, selection, recommendAdministrationCode)` 순수 함수 하나로 모은다 — 화면 상태와 링크가 어긋나지 않게 테스트로 잠근다.

## D4. 개인정보 처리방침 1.1

처리방침 머리 주석이 「분석 도구를 붙이면 제3조·제5조·제9조가 즉시 거짓이 된다」고 적어 두었다. 같은 변경에서 고친다.

| 조    | 바뀌는 것                                                                                                                   |
| ----- | --------------------------------------------------------------------------------------------------------------------------- |
| 제1조 | 목적에 「서비스 개선: 화면 이용 통계 분석」 추가                                                                            |
| 제2조 | 보유 기간 표에 「서비스 이용 통계 — 수집 후 14개월」                                                                        |
| 제3조 | 자동 생성 항목에 Google 애널리틱스 행 추가                                                                                  |
| 제5조 | 위탁·국외 이전 표에 Google LLC(이용 통계 분석, 미국) 추가                                                                   |
| 제9조 | 쿠키 표에 `_ga`·`_ga_<ID>`(2년) 추가, 「분석 도구를 사용하지 않습니다」 삭제, 거부 방법(브라우저 설정·Google 차단 부가기능) |

- 버전 1.1, **시행일 2026-10-09**. 제12조가 시행 7일 전 공지를 정했고, legal.md 가 「시행일을 미래로 두고 먼저 배포」를 허용한다. **측정 ID 는 시행일 이후에 Vault 에 넣는다.**
- 광고 목적 이용·광고 개인화는 하지 않는다고 쓴다 — 태그가 Google 신호·광고 개인화 신호를 끈다(D1-5).
