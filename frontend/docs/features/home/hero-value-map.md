## D2. 동작 요구사항

1. 히어로 지도는 `GET /districts/rankings`(분기 생략 = 서버 최신)의 유동인구 전체 순위로 칠한다. 실패·빈 응답이면 예전처럼 모두 회색이고 범례 글자를 두지 않는다.
2. 단계 계산은 구별현황과 **같은 함수**(`resolveStatusMapValueSteps`)·**같은 다섯 칸**(`STATUS_MAP_VALUE_STEPS`)이다. 홈에서 진한 구는 구별현황 유동인구 탭에서도 같은 농도다.
3. hover 카드(툴팁)와 클릭·탭·Enter 선택 동작은 그대로다. 고른 구와 hover·키보드 포커스 구는 단계 칠 위에 `--color-primary-700` 으로 채운다.
4. 모바일 히어로 아래 지도는 같은 컴포넌트라 같은 칠·범례를 받는다.
5. 조회 수는 목록의 **모든 항목**이 `MIN_VISIBLE_VIEW_COUNT`(10) 이상일 때만 숫자로 적는다. 아니면 숫자·막대 없이 순위·이름·링크만 둔다. 스크린리더 문장에서도 조회 수를 뺀다.
6. 「지금 많이 본 지역」은 지표 순위를 목록으로 그리지 않는다. 지표 토글은 지도 머리에 남고, 지도 칠·범례(「유동인구 Top 5 · 진할수록 위」)·인사이트 한 줄이 지표를 말한다.
7. 모바일 헤더(≤960)는 세션 확인이 끝난 게스트에게만 「로그인」을 햄버거 왼쪽에 둔다. 확인 전(#579)·회원에게는 두지 않는다. 회원가입은 로그인 화면이 잇는다.
   - 햄버거 패널의 계정 항목은 **한 줄**이다(2026-10-10). 게스트는 계정 항목이 없다 — 입구는 햄버거 옆 「로그인」 하나이고 회원가입은 로그인 화면이 잇는다(패널은 화면 이동 5줄뿐). 회원은 아바타·이름 줄 하나이고 누르면 북마크·개인 정보 설정·로그아웃이 펼쳐진다(`/profile` 아래에서는 펼친 채 연다). 예전 회원 메뉴는 9줄이었다.
   - 메뉴가 열려 있는 동안 헤더는 `z-index: 1100` 이다 — 바텀시트(20)·모달(1000) 위, 토스트(1200) 아래. 헤더(20)와 같은 층인 지도 화면 바텀시트가 DOM 상 뒤에 와서 패널을 덮었다.
8. 홈의 색 칠한 증감은 지표 극성(`STATUS_METRIC_POLARITY`)으로 positive/negative/neutral 을 정하고, 부호와 「개선/악화」(툴팁은 화살표 없이 부호 + 글자)를 늘 같이 둔다.

## D4. 상세 동작 정의

### D4-1. 범례와 높이

- 범례는 지도 바로 아래 한 줄(최소 20px, 글자 13px)이다: 기준(「2026년 1분기 유동인구」) · 「많음 ■■■■■ 적음」 · (값 없는 구가 있으면) 「■ 데이터 없음」. 칸 모양은 구별현황 범례와 같다(12px, border-200, radius-compact).
- 범례 `id` 를 svg `aria-describedby` 앞에 잇는다. 지도 중심 배치(641~899)에서 캡션은 눈에서 치우지만 범례는 보인다.
- svg 높이 상한은 범례 한 줄(28px)만큼 줄였다: 좌우 분할 `- 48px - 56px`, 지도 중심 `- 308px`.

### D4-2. 칠 우선순위(CSS)

`fill: surface-muted` → `[data-value-step='1..5']` → `[data-selected='true']` → `:hover` → `:focus-visible`. 단계 규칙이 속성 선택자라 고른 칸 규칙을 그 뒤에 둬야 같은 명시도에서 이긴다.

### D4-3. 「지금 많이 본 지역」 배치

- 조회 목록이 있으면 ≥1200 [많이 본 | 지도(1.15fr)] 두 칸, 그 아래는 지도 → 목록 한 열(지도 최대 560px). 지표만이면 지도 한 칸(최대 560px 가운데).
- 연결선(≥1200·정밀 포인터)은 조회 행 → 지도 구만 남는다.
- 지표 Top 5 의 **이름**은 지도 요약 문장(`aria-label`)이 말한다. 듀얼도 「…표시했어요. 유동인구 Top 5: 강남구, 관악구, …. 둘 다 든 곳은 …」 으로 지표만 분기와 같은 모양이다(리뷰 반영).
- 지표만 상태(조회 n<3·실패) 제목은 「유동인구·매출·개업 상위 자치구를 서울 지도에 칠했어요.」다. 예전 「…수로 자치구를 비교해요.」는 비교할 숫자가 화면에 없어 거짓이 됐다. 새 문장은 dual 에서도 참이라 스켈레톤 문구로도 쓴다.

### D4-4. 모바일 헤더

`[브랜드] … [로그인][☰]`. 로그인은 테두리 없는 글자 버튼(min 44×44, text-700, hover primary-100) — 햄버거(테두리 상자)와 버튼 두 개가 겨루지 않게 한다.

## D5. 비즈니스 로직

- 5분위: 나보다 값이 큰 구의 수 `higher` 로 `floor(higher × 5 / n) + 1`. 25개면 1~~5위 1단계 … 21~~25위 5단계. 동점은 같은 단계.
- 조회 임계값은 **목록 단위**다 — 행마다 정하면 위 몇 줄만 숫자가 있고 아래는 비어 「값을 못 받은 행」처럼 보인다.
- 극성: 유동인구·매출·개업은 높을수록 좋음, 폐업은 낮을수록 좋음. 0·결측은 neutral(무채색, 판단 글자 없음).

## D6. 주의사항

- 히어로 지도 상자는 여전히 800:620 비율이다 — 칠이 오기 전과 후의 높이가 같다. 범례 줄은 늘 자리를 잡는다.
- 홈 히어로는 스크롤 리빌 때문에 헤드리스 스크린샷이 비어 보일 수 있다. 확인은 DOM 측정(`data-value-step` 개수, 범례 글자, 계산 스타일)으로 한다.
- `--color-primary-700` 은 **채움**으로만 쓴다(글자색 금지 가드와 무관).
