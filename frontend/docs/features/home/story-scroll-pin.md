## D3. 아키텍처

```
product-story.tsx
└ Container(section)
  ├ Lead (h2)                      ← 스크롤로 지나간다
  └ PinTrack  (고정 모드: height = (100dvh - 헤더) + 4 × 60dvh)
    └ PinSticky (고정 모드: position: sticky · top: 헤더 · height: 100dvh - 헤더 · 세로 가운데)
      ├ StepTabs
      └ Panel
신규: story-scroll.ts        — 순수 계산(스텝 판정 · 목표 스크롤 위치) + 상수
      use-story-pin.ts       — matchMedia · scroll 리스너(rAF) · scrollToStep
```

```ts
export const STORY_STEP_SCROLL_DVH = 60
export const STORY_PIN_QUERY =
  '(min-width: 1100px) and (min-height: 800px) and (prefers-reduced-motion: no-preference)'

/** pin 구간 안에서 스크롤한 거리 → 단계. 구간 밖은 양 끝 단계로 자른다. */
export function pinnedStepIndex(
  scrolled: number,
  pinSpan: number,
  count: number,
): number

/** 단계 몫의 가운데로 가는 window.scrollY. */
export function pinnedStepScrollTop(
  trackDocTop: number,
  headerPx: number,
  pinSpan: number,
  index: number,
  count: number,
): number
```

- `scrolled = headerPx - trackRect.top` — 트랙 윗단이 헤더 아래 선에 닿는 순간이 0 이다(sticky `top` 과 같은 선).
- `pinSpan = trackHeight - stickyHeight` = 4 × 60dvh. 단계 i 의 몫은 `[i, i+1) × pinSpan / 4`.
- 예전 구현(`viewportProgress` → `pinWindow` → 스텝)은 진행도를 두 번 환산하다 첫·마지막 스텝이 눌리는 결함이 있었다(interaction-polish B2·B4). 트랙 위치에서 곧장 나눈다.

## D4. 상세 동작

### D4-1. 모드

- 고정 모드 판정은 CSS 와 JS 가 **같은 문자열**(`STORY_PIN_QUERY`)을 쓴다.
- JS 가 아직 모드를 모르는 첫 렌더는 클릭 모드로 그린다. CSS 가 이미 트랙을 늘려 두었으므로 높이는 튀지 않고, 마운트 직후 스크롤 위치로 선택을 맞춘다.
- 모드가 바뀌면(창 크기 변경) 다시 판정한다. 클릭 모드로 돌아가면 마지막 선택을 그대로 둔다.

### D4-2. 스크롤 → 선택

- scroll·resize 를 rAF 로 묶어 한 프레임에 한 번 잰다. 단계가 바뀔 때만 state 를 바꾼다.
- 트랙에 닿기 전은 01, 지난 뒤는 04 다.

### D4-3. 선택 → 스크롤

- 고정 모드의 `onSelect(i)` 는 state 를 바로 바꾸지 않고 `pinnedStepScrollTop` 으로 스크롤한다. 선택은 스크롤 결과로 따라온다(두 정본을 만들지 않는다).
- 키보드 포커스는 그 탭으로 옮긴다(탭은 sticky 라 화면에 남는다).

## D6. 주의사항

- **e2e 기준선을 올린다.** runbook(qa.md §4)은 「기준선은 나아진 값으로만 내린다」지만, 이것은 사용자가 비용을 알고 고른 구조 변경이다(D0 「비용」). 갱신 커밋에 전/후 값과 이 명세를 적는다. `docHeightScreens`·`stickyTrackPx`·`stickyTrackShare` 외의 지표는 나빠지면 안 된다.
- 자동화 브라우저가 숨겨지면 scroll·rAF 가 멈춘다(interaction-polish D8-10). 고정 모드 검증은 헤드리스(gstack browse)로 한다.
- 03 게이트(탭 목록이 다 보일 때)는 sticky 안에서도 그대로 성립한다.
