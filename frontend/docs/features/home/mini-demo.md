# home — 상권 분석 미니데모 세부 명세서

> **작성일**: 2026-08-07
> **공통 명세**: [home 공통 명세](./home.md)
> **대상**: 웹 (Next.js App Router)
> **작성자**: Claude Code
> **상태**: 초안

홈의 인터랙티브 주인공. 방문자가 **지역·업종을 골라 상권 분석 결과를 미리 체험**하게 하여, 설명 없이도 서비스의 핵심 가치(상권 분석)를 이해시킨다. 백엔드 없이 **정적 샘플 데이터**로만 동작한다.

## D1. 기능 개요

```
지역 선택(구) + 업종 선택 → key = `${districtId}:${industryId}` → home-demo 데이터 조회
  → 분석 카드 리렌더(매출 스파크라인·유동인구·경쟁강도·해석) → "이 조건으로 실제 분석하기" CTA → /analysis
```

- 초기 진입 시 대표 조합(예: 강남구·카페)이 기본 선택되어 카드가 채워진 상태로 보인다(빈 상태 없음).
- 선택 조합에 전용 데이터가 없으면 **대표 샘플**로 폴백한다(항상 채워진 카드 유지).

### D1-1. UI 진입점 / 기능 연결

> **라우트/위치**: `app/(shell)/page.tsx` → `src/components/home/home-page.tsx` 내 Hero 직후 섹션. 데모 본체는 `src/components/home/analysis-mini-demo.tsx`(`'use client'`).
> **데이터**: `src/data/home-demo.ts`(정적).

| UI 요소            | 사용자 동작   | 결과 / UI 반영                                        |
| ------------------ | ------------- | ----------------------------------------------------- |
| 지역 선택          | 클릭/키보드   | 선택값 갱신 → 카드 리렌더                              |
| 업종 선택          | 클릭/키보드   | 선택값 갱신 → 카드 리렌더                              |
| 분석 카드          | (표시)        | 매출 스파크라인·유동인구·경쟁강도·한 줄 해석 갱신      |
| "실제 분석하기" CTA | 클릭          | `/analysis`로 이동                                    |

## D3. 아키텍처 / 시스템 설계

| 모듈                                          | 책임                                                                 |
| --------------------------------------------- | -------------------------------------------------------------------- |
| `src/components/home/analysis-mini-demo.tsx`  | `'use client'` 데모 본체 — 선택 상태·카드 렌더·CTA                    |
| `src/components/home/sparkline.tsx`           | 정적 숫자 배열 → 인라인 SVG 폴리라인(스파크라인). 순수·재사용         |
| `src/data/home-demo.ts`                       | 정적 샘플 데이터·타입·조회 함수(`getDemoSample`)·기본 선택값          |
| `src/components/home/home-page.tsx`           | 서버 컴포넌트 유지, 데모 섹션만 client 경계로 삽입                    |

**타입(초안):**
```ts
export type CompetitionLevel = 'low' | 'medium' | 'high'
export type DemoSample = {
  districtId: string
  industryId: string
  salesTrend: number[] // 최근 6개월 대표 지수(스파크라인)
  salesChangePct: number // 전월 대비 %(부호 포함)
  footTraffic: string // 표시용 문자열(예: "일평균 4.2만 명")
  competition: CompetitionLevel
  insight: string // 한 줄 해석
}
export const DISTRICTS: { id: string; name: string }[]
export const INDUSTRIES: { id: string; name: string }[]
export const DEFAULT_SELECTION: { districtId: string; industryId: string }
export function getDemoSample(districtId: string, industryId: string): DemoSample // 없으면 대표 폴백
```

**설계 결정**: 홈 서버 컴포넌트는 유지하고, 상호작용이 필요한 데모만 `'use client'`로 격리한다. 스파크라인은 인라인 SVG로 의존성 0. `getDemoSample`은 순수 함수로 단위테스트 대상.

## D4. 상세 동작 정의

### D4-1. 선택 → 조회 → 렌더
- 지역/업종 UI는 접근성 있는 선택 컨트롤(예: 라디오 그룹형 세그먼트 또는 `<select>`)로 구현하며 키보드로 조작 가능.
- 선택 변경 → `getDemoSample(districtId, industryId)` → `DemoSample` → 카드 각 요소 갱신.

### D4-2. 카드 구성
- 매출 추이: `Sparkline`(salesTrend) + `salesChangePct` 배지(양수/음수 색은 `--color-success`/`--color-danger`).
- 유동인구: `footTraffic` 텍스트.
- 경쟁 강도: `competition` → 배지(낮음/보통/높음). 색은 기존 시맨틱 토큰 범위 내.
- 해석: `insight` 한 줄.
- 라벨: "대표 예시 데이터" 명시.
- CTA: "이 조건으로 실제 분석하기" → `/analysis`.

## D6. 주의사항

| 항목            | 내용                                                                                     |
| --------------- | ---------------------------------------------------------------------------------------- |
| 데이터 오인 방지 | 반드시 "대표 예시/샘플" 라벨. 실제 수치처럼 정밀하게 표기하지 않음                        |
| 접근성          | 선택 컨트롤 키보드 조작·포커스 표시, 카드에 `aria-live="polite"`로 갱신 안내              |
| 모션            | `--motion-fast`/`--ease-standard` 등 토큰만. `prefers-reduced-motion`에서 제거           |
| 의존성          | 차트 라이브러리 추가 금지 — 스파크라인은 인라인 SVG                                       |
| 디자인 토큰     | 새 색/radius/shadow 토큰 추가 금지(DESIGN.md 준수)                                        |
| 카피 보이스     | 해석 문구도 구체·직설·전문(과장·AI 상투구 배제)                                           |
