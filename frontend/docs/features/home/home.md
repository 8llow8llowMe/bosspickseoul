## S1. 기능 개요

홈은 BossPickSeoul의 서비스 진입점으로, 첫 방문자가 **랜딩만 보고도 "서울 상권을 업종별 데이터로 분석해 창업을 판단하는 서비스"임을 이해**하도록 한다. 핵심 가치를 말로 설명하는 대신 **상권 분석 미니데모**로 직접 체험시키고, 판단 흐름과 기능을 이어서 안내한다. 로그인 분기는 없고, 미니데모는 정적 샘플 데이터로만 동작한다.

**데이터 요청은 「지금 많이 본 지역」 섹션 하나뿐이다**(v2.2에서 추가). 그 전까지 홈은 완전 정적이었고, 이 섹션은 실패하면 스스로 빠져 나머지 홈을 정적일 때와 동일하게 유지한다.

```
홈 진입 → Hero(구체 카피+CTA) → 상권 분석 미니데모(지역·업종 선택→샘플 카드 반응) → 판단 흐름(스크롤 등장) → 지금 많이 본 지역(라이브 순위) → 기능 → 마무리 CTA → 대상 라우트로 이동
```
