## S0. 배경 / 기획 의도

NowDoBoss → BossPickSeoul 리브랜딩과 함께 프론트엔드를 React/Vite(CRA) 구조에서 Next.js App Router로 이관하는 작업의 일환으로, 서비스 진입점인 홈(랜딩) 화면을 이관한다.

> **마이그레이션 컨텍스트**: 레거시 시스템을 웹(App Router)으로 이전하는 작업이므로 as-is/to-be를 구분해 기술한다.

## S1. 기능 개요

홈은 BossPickSeoul의 서비스 진입점으로, 첫 방문자에게 핵심 기능(구별현황, 상권분석, 상권추천, 시뮬레이션, 커뮤니티/채팅 등)을 정적 랜딩 섹션으로 소개하고 각 기능 화면으로 안내한다. 사용자 입력, 데이터 요청, 인증 분기 없이 서버에서 렌더 가능한 콘텐츠와 `next/link`만 사용한다.

```
홈 진입 → Hero → Quick actions → Workflow → Services → Metrics → CTA 클릭 → 대상 기능 라우트로 이동
```
