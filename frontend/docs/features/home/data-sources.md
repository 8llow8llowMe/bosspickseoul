## D4. 상세 동작 정의

### D4-1. 위치 · 구성

```
home-page.tsx: Hero → ProductStory → PopularDistricts → DataSources → FeatureBento   ← 2026-09-30 순서 변경(full-screen-sections-and-live-tooltip D4-3)
data-sources.tsx
├ 머리말: 아이브로 「데이터 출처」 · h2 「판단 근거는 모두 공공데이터에서 가져와요.」 · 한 문장
├ 카드 격자 4열(서울 카드 2칸 + 공정위 + 한국부동산원) · ≤900 2열(서울 2칸) · ≤560 1열
└ 보조 한 줄(매장용빌딩 통계 · 04 예시 대표값 고지)
```

### D4-2. 카드

- 머리: 아이콘 칸(36px, 일반 아이콘 — 서울 `Landmark` · 공정위 `BriefcaseBusiness` · 한국부동산원 `Building2`) + 기관명(16px/700) + 경로(13px `--color-text-700`, 예: 서울시 상권분석서비스 · 공공데이터포털).
- 데이터셋 칩(13px/600 `--color-text-700`, pill).
- 꼬리(위 경계선): 판단 단계 배지(`01`~`04`, 12px/700) · 규모 또는 용도 · 원문 링크.
- 서울 카드만 배경 `--color-background-muted`, 나머지는 흰 바탕 — 가장 많이 쓰는 출처를 한 단계 띄운다.
- 서울 카드 규모: `자치구 {districts.length} · 행정동 425 · 상권 1,650`. 425·1,650 은 영역 데이터셋(OA-22160 · OA-15560) 행 수다(backend 적재 문서). 재적재로 바뀌면 함께 고친다.
- 보조 줄: 「보조로 서울시 매장용빌딩 임대료·공실률 통계를 함께 봐요. 홈의 04 예시는 이 데이터로 만든 대표값이에요.」

### D4-3. 기준 시점

- `{formatPeriodCode(Top10 응답 currentPeriodCode)} 기준 · 분석·추천` — 예: 「2026년 1분기 기준 · 분석·추천」.
- 분기 상수가 바뀌면 자동으로 따라간다. 응답에서 받는 것은 백엔드 계약 변경이라 범위 밖(D0).
