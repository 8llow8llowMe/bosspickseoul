## D1. 기능 개요

```
≥1200 (3칸):  [ 많이 본 Top 8 ]  [ 지도 ]  [ 지표 토글 · Top 5 ]      ← 연결선은 이 배치에서만
901~1199:     [ 지도 (최대 560px, 가운데) + 범례 ]
              [ 많이 본 Top 8 ]  [ 지표 Top 5 ]                          ← 행 ↔ 구 강조만
≤900:         [ 지도 (폭 가득) + 범례 ] → [ 많이 본 ] → [ 지표 ]          ← 강조 없음(호버 없음)
```

인사이트 문장(`InsightSlot`)은 지금처럼 목록들 위에 둔다. 인사이트가 가리키는 구(`highlightCode`)는 지도에서도 기본 강조되고, 3칸
배치에서는 그 연결선이 처음부터 그려져 있다 — 문장 → 행 → 지도가 한 줄로 이어진다.

### D1-1. UI 진입점 / 기능 연결

| 진입점                 | 동작                                                                             |
| ---------------------- | -------------------------------------------------------------------------------- |
| 섹션이 화면에 들어옴   | 등장 연출 1회(D4-4)                                                              |
| 많이 본 행 호버·포커스 | 그 구 강조 + 연결선(3칸). 행 클릭은 지금처럼 `/analysis?districtCode=…`          |
| 지표 행 호버           | 그 구 강조 + 연결선(3칸). 지표 행은 지금처럼 링크가 아니다                       |
| 지도 폴리곤 호버       | 그 구가 들어 있는 **양쪽** 행 강조 + 연결선(3칸). 클릭은 아무 일도 하지 않는다   |
| 지표 토글              | 칠이 새 지표 Top 5 로 크로스페이드, 인사이트·기본 강조가 새 문장 기준으로 바뀐다 |

## D4. 상세 동작 정의

### D4-1. 칠·배지·범례

| 요소         | 규칙                                                                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 기본 구      | fill `--color-surface-muted` · stroke `--color-border-200` 1px(`non-scaling-stroke`)                                                             |
| 지표 칠      | 순위 r → `color-mix(in srgb, var(--color-primary-600) {60,46,33,21,11}%, var(--color-surface))`. 파랑은 이 한 계열뿐(DESIGN.md 지도 규칙)        |
| 배지         | 구 `center` 에 원. **화면 지름 22px 고정**(지도 배율의 역수로 키운다 — 히어로 툴팁 보정과 같은 방식). 원 `--color-text-900` · 숫자 흰색 12px 700 |
| 강조(active) | stroke `--color-primary-700` 2.5px, 나머지 구 opacity 0.55. 배지는 낮추지 않는다                                                                 |
| 범례         | 지도 아래 13px. 칠 견본 다섯 칸 + 「{지표} Top 5 · 진할수록 위」 · 배지 견본 + 「많이 본 순위」                                                  |

### D4-2. 연결선 (≥1200 · 정밀 포인터)

- 덮개 SVG 는 목록 3칸 래퍼(`Columns`)를 덮는다(`position: absolute; inset: 0`). 좌표는 래퍼 기준.
- 시작점: 많이 본 행이면 행의 **오른쪽** 가장자리 세로 가운데, 지표 행이면 **왼쪽** 가장자리 세로 가운데(`[data-rank-key]` 로 찾는다).
- 끝점: 지도 svg 의 `getScreenCTM()` 으로 feature `center` 를 화면 좌표로 바꾼 뒤 래퍼 기준으로 뺀다.
- 모양: `M s C (s.x+dx, s.y) (e.x-dx, e.y) e`, `dx = (e.x - s.x) × 0.5`(부호 포함 — 지표 행은 왼쪽으로 나간다). stroke `--color-primary-700` 1.5px, 끝에 반지름 3 점.
- **배지가 얹힌 구로 가는 선은 배지 가장자리에서 멈춘다**(구현 중 결정). 중심까지 그으면 선과 끝점이 배지 숫자를 가렸다(1440 실측, 강남구 「2」). 베지어가 수평으로 닿으므로 끝을 가로로 12px(배지 반지름 11 + 여유) 당기고, 배지가 끝 표시라 점은 찍지 않는다.
- 활성 구가 양쪽 목록에 다 있으면 선 두 줄(겹침이 한눈에). 한쪽에만 있으면 한 줄. 어느 목록에도 없으면(폴리곤만 호버) 없음.
- 그리기: `stroke-dasharray = 길이`, `stroke-dashoffset` 길이 → 0 을 `--motion-standard` · `--ease-enter`. 활성 구가 바뀌면 바로
  새 선(이전 선은 지운다 — 남아 있는 선이 흐름을 흐린다).
- 재계산: ResizeObserver(래퍼·지도) · 지표 토글 · 폰트 로드 뒤. 스크롤에는 다시 재지 않는다(래퍼 기준 좌표라 불변).

### D4-3. 상호작용과 접근성

- 행: `RankBarList` 의 기존 링크(많이 본)·비링크(지표) 그대로. 포커스(많이 본 링크)도 호버와 같은 강조 — 키보드 사용자도 선을 본다.
- 폴리곤: `onPointerEnter/Leave` 만. `role`·`tabIndex` 없음, 클릭 무반응, 커서 기본값. 터치(≤900·`hover: none`)에서는 호버 처리를 붙이지
  않는다(탭이 hover 를 흉내 내 강조가 남는 것을 막는다).
- 강조는 색과 함께 **굵기·투명도**로도 드러난다. 정보 자체(순위·값)는 늘 목록에 있다 — 호버로만 드러나는 정보가 없다.

### D4-4. 등장 연출 (1회)

| 순서 | 무엇                                                   | 시간                                       |
| ---- | ------------------------------------------------------ | ------------------------------------------ |
| 1    | 지도 실루엣(기본 구) 보임                              | 즉시(스켈레톤과 같은 모양이라 바뀜이 없다) |
| 2    | 지표 칠 — 5위 → 1위 순으로 채워짐                      | 각 `--motion-standard`, 간격 80ms          |
| 3    | 배지 — 8위 → 1위 순으로 나타남(scale .6 → 1 · opacity) | 각 `--motion-fast`, 간격 40ms              |
| 4    | 인사이트 연결선 그리기(3칸)                            | `--motion-standard`                        |

- 시작 조건: 지도 상자가 30% 보일 때(threshold 0.3). 데이터가 늦게 오면 도착한 뒤 2~4 를 한다(이미 보이고 있으면 바로).
- 지표 토글: 칠만 `--motion-slow` 크로스페이드. 배지는 그대로.
- `prefers-reduced-motion: reduce`: 1~4 모두 최종 상태로 즉시. 토글도 즉시.

### D4-5. 레이아웃·높이

| 폭       | 그리드                                                                                       | 지도        |
| -------- | -------------------------------------------------------------------------------------------- | ----------- |
| ≥1200    | `minmax(0, 1fr) minmax(0, 1.15fr) minmax(0, 1fr)` · 간격 32 (1440 → 목록 424 · 지도 488×378) | 세로 가운데 |
| 901~1199 | 지도 행(최대 560px 가운데) + `1fr 1fr` 목록 행                                               | 위          |
| ≤900     | 1열: 지도(폭 가득, 375 → 335×260) → 많이 본 → 지표                                           | 위          |

- 1440×900: 제목 2줄 예약(72) + 인사이트(52) + 목록 8행(약 420) — 지도 378 은 목록 높이 안에 든다. 섹션 높이 예산(home-restructure D0-2)
  안이다.
- ≤900 은 지도 + 범례로 약 290px 늘어난다(375 문서 약 +0.36 화면). 기준선 `docHeightScreens` 를 함께 갱신한다.

## D5. 비즈니스 로직

### D5-1. `activeCode` 판정

```
activeCode = hoverCode ?? insight?.highlightCode ?? null
```

- `hoverCode` 는 행·폴리곤의 enter 에서 켜고, **같은 코드**의 leave 에서만 끈다(행 → 이웃 행 이동 때 깜빡임 방지).
  - 끄기는 한 틱(`setTimeout 0`) 미루고 다음 enter 가 취소한다. 이웃 행으로 옮기면 A 의 leave 가 B 의 enter 보다 먼저 와서,
    바로 끄면 그 사이 인사이트 강조로 돌아갔다 오며 선이 한 번 더 그려졌다. 행 핸들러는 링크가 아니라 행(`li`)에 단다 —
    구분선 1px 가 링크 밖이다.
  - 호버 핸들러가 사라지면(폭이 901 아래로) `hoverCode` 를 지운다.
- 강조(`data-highlighted`·배경)는 `activeCode` 를 따르지만 `aria-current` 는 인사이트 `highlightCode` 에만 둔다(`RankBarList` 의 `currentKey`).
- 지표 토글 시 `hoverCode` 를 지운다(바뀐 목록에 그 행이 없을 수 있다).

### D5-2. 요약 문장(`summary`, 지도 `aria-label`)

| 상태   | 문장                                                                                                      |
| ------ | --------------------------------------------------------------------------------------------------------- |

## D6. 주의사항

- **배지 겹침**: 종로·중구처럼 작은 구가 붙어 있어 22px 배지가 겹칠 수 있다. 중심 좌표를 그대로 쓰되, 겹치면 순위가 낮은 배지를 위로
  그린다(높은 순위가 가려지지 않게 높은 순위를 나중에 그린다). 실측 후 필요하면 개별 오프셋 표(D8-1).
- **같은 Top 5 를 두 번 보이지 않는다**: 지도는 목록을 되풀이하지 않고 「어디 · 겹침」만 더한다 — 값·변화율 라벨을 지도에 쓰지 않는다.
- 지도 영역은 `role="img"` 한 덩어리 — 스크린리더는 요약 한 문장을 듣고, 상세는 목록에서 읽는다.
- 홈 감사 지표: 새 글자 크기는 12·13px(스케일 안). 대비 — 흰 숫자 / `--color-text-900` 원은 AA 를 넘는다. 폴리곤이 포커스되지
  않으므로 작은 터치 타깃이 늘지 않아야 한다(실측 확인).
- 연결선 덮개는 `pointer-events: none` — 행 클릭·호버를 가로채지 않는다.
