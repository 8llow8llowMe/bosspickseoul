## 상태 범례

⬜ 미착수 · 🟡 명세 작성중 · 🟩 명세 완료 · ✅ 이관·검증 완료 · 🟦 구현 완료·명세 미작성

> **🟦 는 「코드가 문서보다 앞서 있다」는 표시다.** 화면이 이미 서비스되고 있으니 ⬜(미착수)로
> 두면 거짓이고, 정본 명세가 없으니 🟩(명세 완료)로도 둘 수 없다. 이 칸은 **공통명세를 쓰면
> 해소된다.** 공통명세 파일이 없는 Feature 는 링크를 걸지 않는다 — 죽은 링크가 「문서가 있다」는
> 인상을 준다.

## 이관 순서

공통 인프라 → home/auth → status/recommend → analysis/simulation → community → profile → chatting.

## 이관 기록 방식

각 Feature 이관 시: legacy source 파일, target 파일, 상태, known gaps, 검증 결과, 남은 작업을 해당 Feature 공통명세 S0/변경이력에 남기고 이 표의 상태를 갱신한다.
