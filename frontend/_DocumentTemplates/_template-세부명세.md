## D4. 상세 동작 정의

공통 명세 S3에서 요약된 기능을 구현 수준으로 상세화합니다.
처리 규칙은 조건·계산식을 빠짐없이 기술합니다.
API 통신은 엔드포인트·헤더·요청·응답 스펙을 이 문서에 중복 기술하지 않고 **외부 API 문서(Swagger/OpenAPI 등)를 참조**합니다.
이 문서에는 이 기능이 **어떤 API를 어떤 순서로 호출하고, 응답을 어느 내부 모델로 매핑하는지**만 기술합니다.
**API 문서 링크가 제공되지 않은 경우 AI는 엔드포인트·스펙을 임의로 작성하지 않고, 작성자에게 API 문서 위치를 문의합니다.**
