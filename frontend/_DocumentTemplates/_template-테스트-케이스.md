## T0. 범위 구분 기준

각 TC는 검증 범위에 따라 **공통(S)** 또는 **세부(D)** 로 분류합니다.

| 범위 | 의미 | 검증 대상 | 배치 위치 | TC ID 형식 |
|---|---|---|---|---|
| `S` (공통) | 기능 전체에 걸친 공통 동작·요구사항 | 공통 명세 S2 동작 요구사항, S3 필수 기능 | 공통 명세 하위 | `TC-NNN` |
| `D` (세부) | 특정 세부 기능에만 해당하는 동작 | 세부 명세 D4 상세 동작, D5 비즈니스 로직 | 세부 명세 하위 | `TC-{접두사}-NNN` |

> - 분류는 **검증 의도**로 결정합니다. "기능 전체가 충족해야 하는가" → `S`, "이 세부 기능만의 동작인가" → `D`.
> - TC ID는 범위 간·세부 기능 간 번호가 겹치지 않도록 기능 접두사를 권장합니다. 예: `TC-DL-001` (다운로드).
